# Практика 18. Згенеровані стовпці у SQLite

**Варіант 1 — таблиця `books`.** Використано базу з практики 17.

## Завдання 1. Похідне числове значення

Додано `copies_two_branches`, формула `copies_count * 2`. Це умовна кількість примірників, якщо бібліотека веде облік для двох однакових філій: значення основної кількості примірників множиться на два. Значення обчислюється SQLite, а не вводиться вручну.

## Завдання 2. Похідний логічний прапорець

`is_technical_book` має формулу `genre IN ('Технології', 'Програмування')`. Для цих жанрів прапорець дорівнює 1, для інших — 0. Порівняння з `NULL`, якщо жанр буде NULL, дасть NULL, хоча в цій таблиці `genre` визначено як NOT NULL.

## Завдання 3. Свідома помилка прямого запису

Спроба `UPDATE books SET copies_two_branches = 1 WHERE id = 1;` завершується помилкою SQLite:

`cannot UPDATE generated column "copies_two_branches"`

## Завдання 4. Автоматичний перерахунок

До зміни для книги з `id=1` було `copies_count = 4` і `copies_two_branches = 8`. Команда змінила базову кількість на 6. Після зміни `copies_two_branches` стало 12. SQLite перерахував VIRTUAL-значення автоматично, без окремого запису в похідний стовпець.

## Завдання 5. WHERE за згенерованим стовпцем

Використано `WHERE copies_two_branches >= 6`. Це читається простіше, ніж повторювати `copies_count * 2 >= 6`, а назва похідної колонки пояснює, за яким показником відбираються записи. Формулу можна змінити в одному місці — визначенні колонки.

## Контрольні питання

1. **Чому лише VIRTUAL?** В `ALTER TABLE` SQLite дозволяє додати `VIRTUAL` generated column, але `STORED` не можна додати через `ALTER TABLE ADD COLUMN`: для STORED потрібно перерахувати й фізично зберегти значення для всіх наявних рядків, що ця операція не підтримує.
2. **Видалення базової колонки.** SQLite не дозволить видалити базову колонку, якщо від неї залежить generated column; спершу потрібно прибрати залежний generated column.
3. **Чому прямий запис заборонено — перевага?** Значення обчислюється з базових даних, тому не можна вручну записати невідповідне значення. Це забезпечує узгодженість і прибирає потребу оновлювати похідні дані окремо.
